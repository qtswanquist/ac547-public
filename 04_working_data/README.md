# Working with Data

Before starting this module, work through the [Statistical Concepts](../03_data_analytics_statistics/statistical_concepts.ipynb) notebook. It covers measures of location and variability, distributions, and sampling. This module assumes you are comfortable loading a dataset, running code in a notebook, and describing what you see.

This module is organized into three folders. Work through them in order — each folder holds its own notebooks and the datasets those notebooks need.

1. [Wrangling Concepts](04.1_wrangling_concepts) — the tutorial notebook for this module. It covers tidy data, number and date formats, duplicates, missing values, reshaping, joining, and sampling.
2. [Diamonds Exercise](04.2_diamonds_exercise) — take a clean dataset apart and put it back together, practicing exports, imports, reshapes, and joins.
3. [Sales Exercise](04.3_sales_exercise) — an audit task that applies the whole module to three related datasets from a simulated audit client.
