## Datasets

The datasets used in this module are stored in this folder alongside the notebook, so the notebook loads them by filename (e.g., `pd.read_csv('coozie_data.csv')`).

### Coozie Data (coozie_data.csv)

The Coozie dataset contains temperature measurements from a controlled experiment designed to evaluate the insulating effectiveness of different beverage coozies over time. Identical cold beverages were placed in three conditions: a control (no coozie), a soft coozie, and a stainless steel coozie. Temperature readings were recorded at regular time intervals.

Source: Original data collected for this course

### Diamonds Data (diamonds.pkl)

The Diamonds dataset is a large, structured dataset containing detailed attributes of nearly 54,000 diamonds, including physical measurements, cut quality, color, clarity, and price.

Source: Seaborn package
